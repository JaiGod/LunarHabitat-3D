# Lunar Habitat 3D Models

Interactive glTF 2.0 models of the NASA HUNCH **Lunar Smart Adaptive Habitat**, shown in the browser with `<model-viewer>`.

**Live site:** https://jaigod.github.io/LunarHabitat-3D/
**Main project:** https://jaigod.github.io/LunarSmartAdaptiveHabitat/

| Model | File | Size | Triangles |
|---|---|---|---|
| Full habitat site (terrain, pads, Earth) | `models/habitat.glb` | 920 KB | 181,236 |
| Habitat, color model | `models/habitat_base_color.glb` | 400 KB | 39,500 |
| 1:50 3D-print parts (6 parts) | `models/print_parts_1to50.glb` | 252 KB | 38,520 |

All models were exported from the original Blender files with Draco mesh compression and pass the Khronos glTF Validator with 0 errors and 0 warnings. You can open any `.glb` in VS Code with the glTF Tools extension to inspect or preview it.
